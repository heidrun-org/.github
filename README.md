# Heidrun organization profile

This repository holds the public introduction shown on the [Heidrun organization profile](https://github.com/heidrun-org).

## Update the organization profile

Edit [profile/README.md](profile/README.md) and commit the change to `main`. GitHub displays that file on the organization's Overview page.

The root `README.md` describes this repository. The file `profile/README.md` provides the introduction shown on the organization profile.
