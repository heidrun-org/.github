# Heidrun

**Keep your agents working. Know which one needs you.**

With AI, every developer is THE GOAT!

[Website](https://heidrun-org.github.io/) · [Documentation](https://heidrun-org.github.io/heidrun/documentation/) · [Download](https://github.com/heidrun-org/heidrun/releases/latest)

</div>

Heidrun is a macOS application for managing coding agents across projects, workspaces, tabs, and panes. Keep coding agents in one window and see which coding agent needs a decision, permission, or review.

- Organize coding agents in workspaces, tabs, and panes with real terminals.
- Use the Needs you sidebar section to find coding agents waiting for your attention.
- Send reusable instructions with macros and keep Claude and Codex quotas in view.
